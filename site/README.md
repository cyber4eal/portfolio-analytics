# site/

`index.html` + `app.js` are the page. `data.json` is generated by
`python3 -m fundengine build` and is **git-ignored on purpose** — it carries
live holdings, euro values and the book total.

All arithmetic runs in `app.js`, from the daily return matrix the build
ships. That is what makes the holdings editable: the page recomputes
volatility, beta, drawdown, correlations and the blend from weights, so an
edit changes every number rather than just the row it touched. Edits live in
`localStorage` for that browser only and are never written back to the
sheet.
